Authority Studio

Solana tokens have three separate authority lanes. Each one is independent and can be kept, transferred to another wallet, or permanently revoked. Revocations are irreversible.

🌿

Mint Authority

Controls the ability to create more tokens and increase the supply. If revoked, the supply is permanently fixed.

⚠️ Revoking mint authority is permanent. Supply cannot be increased after this.
❄️

Freeze Authority

Controls the ability to freeze or thaw specific token accounts. If revoked, account freezing is permanently disabled.

⚠️ Revoking freeze authority is permanent. Token accounts cannot be frozen after this.
📝

Metadata Update Authority

Controls the ability to edit the token's metadata: name, symbol, image, description. If revoked, metadata is permanently locked.

⚠️ Revoking metadata update authority is permanent. Token metadata cannot be changed after this.
